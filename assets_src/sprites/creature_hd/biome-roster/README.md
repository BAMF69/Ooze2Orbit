## ImageGen prompt set

Use the approved creature portrait for identity and a shipped Water atlas for style. Keep the palette and silhouette, with dark ink outlines, cel shading, restrained texture, and warm upper-left light. Generate five isolated right-facing side-view poses with transparent gutters. Use three columns by two rows and leave the final cell empty.
