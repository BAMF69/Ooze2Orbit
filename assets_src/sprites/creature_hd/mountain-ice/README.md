# Mountain and Ice sprite atlases

Each transparent PNG master has a WebP copy. The atlas uses the Water layout of four columns and five rows. Rows are patrol, tell, strike, recovery and down. Scree Roller's strike row rotates the curled pose through four quarter turns. Other rows are painted phase poses held across four atlas cells.

## ImageGen prompt set

Use the approved creature concept for identity and the shipped Water atlas for paint style. Ask for bold ink, broad shadow shapes, restrained brush texture, warm upper-left lighting, consistent anatomy, and readable right-facing side-view silhouettes. Generate five isolated, transparent pose sources in a three-column by two-row grid with an empty final cell. Leave clear gutters and omit labels, background, props, and effects.

| Creature | Water reference | Pose prompts in order |
|---|---|---|
