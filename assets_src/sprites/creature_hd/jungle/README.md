# Jungle enemy sprite atlases

The PNGs are atlas masters. The WebPs are compressed copies with alpha. Each atlas has 20 frames in a four-column grid. Rows are patrol, tell, strike, recovery and down. Snapfrond uses 120 px cells. The other three use 96 px cells. The four columns use the same painted pose with subtle offsets, following the Water atlas conventions. Snapfrond's down row shows the honeycomb seal.

## ImageGen prompt set

Use the matching character from the approved Jungle concept sheet for identity and the matching shipped Water atlas for style. Generate a transparent side-scroller pose source with heavy dark ink, cel-shaded shadows, restrained paint grain and warm upper-left lighting. Use a three-column, two-row grid with one isolated sprite per cell and an empty last cell. Keep silhouettes readable at game scale, with consistent anatomy and transparent gutters. Exclude labels, scenery, shadows and effects.
